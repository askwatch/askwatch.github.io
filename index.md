# AskWatch on GitHub

[AskWatch](https://askwatch.ai/?ref=github-pages) is an AI visibility tracker: it shows how often ChatGPT, Perplexity, Gemini, Copilot and Google AI name your brand, where you rank in the answer, and which pages they cite.

This is where the parts of it that anyone can use are published in the open.

## Repositories

- **[AI crawlers list](https://askwatch.github.io/ai-crawlers/)** ([repo](https://github.com/askwatch/ai-crawlers)): 26 AI and search crawlers with their robots.txt tokens, operators, documented user agents, IP ranges and reverse DNS, as JSON and CSV. Every entry is sourced from the operator's own documentation. CC BY 4.0.
- **[Google Search Console MCP](https://github.com/askwatch/gsc-mcp)**: documentation for the free hosted MCP server that lets Claude, ChatGPT, Cursor and other AI clients read your Search Console data. Read-only, no Google Cloud project.
